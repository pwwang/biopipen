Build an indexed reference genome for split-pipe

Runs split-pipe --mode mkref, which is required before any data can be processed. The output of this process is used by SplitPipeCount with envs.genome_dir. Requires the Parse Biosciences Pipeline (split-pipe) v1.9.0+.

Run split-pipe on one sublibrary

Runs split-pipe --mode all to pre-process, align and post-process the sequencing data of a single sublibrary, and to generate the expression matrices and the report for it. Requires the Parse Biosciences Pipeline (split-pipe) v1.9.0+.

Terminology: a "sublibrary" is one well-pool of a kit processed by --mode all (i.e. the fastq files of one sample well-pool of one sequencing run). Sublibraries are always processed independently and must never be merged at this step: fastq files from multiple sequencing lanes of the SAME sublibrary are passed together as a list to in.fq1, while fastq files of DIFFERENT sublibraries belong in different jobs of this process. Sublibraries are merged into a single dataset afterwards, using SplitPipeCombine (--mode comb).

Combine sublibraries into a single dataset

Runs split-pipe --mode comb to merge the outputs of the sublibrary (one well-pool processed by --mode all) directories of one sequencing run into a single dataset with a new report. Requires the Parse Biosciences Pipeline (split-pipe) v1.9.0+.

Terminology: each sublibrary is one well-pool processed by SplitPipeCount (--mode all). Only sublibraries of the same library preparation can be combined (for example multiple WT sublibraries), and sublibraries must have been processed with the same version of the pipeline as the one used here. Chemistry, kit and sample definitions are parsed from the sublibrary directories, so they are not passed to --mode comb.

Summarize split-pipe metrics

Merges the metrics files of the sublibrary (or combined) output directories of SplitPipeCount/SplitPipeCombine into one table. The names of the metrics files are version-dependent, so they are discovered with envs.metrics_glob and the process fails if nothing matches.
